# Notebook generators and screening scripts

The v4–v8 optimizer notebooks and the transport characterization notebook in `..` were generated by these scripts.
Edit and re-run a script rather than hand-editing a generated notebook. Output paths are absolute (this workstation).

| Script | Generates |
|---|---|
| `build_v4.py` | `SingleLayer_ComplexPB_v4.ipynb` (Im γ objective, two-fin, fixed probes) |
| `build_nb.py CFG` | engine-agnostic Im γ optimizer (v5): `configs/cfg_v5.json` |
| `build_nb2.py CFG` | + stochastic locality/robustness probes and linearity (v6a/v6b): `configs/cfg_v6*.json` |
| `build_nb3.py CFG` | η-control objective with the same probes and a gap floor (v7a/v7b/v8): `configs/cfg_v7*.json`, `cfg_v8.json` (v8 also sets `W_LOC = 60` after generation) |
| `build_transport_nb.py` | `TwoFin_ComplexPB_Transport_Characterization.ipynb` (paper verification, stacks, lateral supercells) |

Run with the project environment, e.g. `python build_nb3.py configs/cfg_v7b.json`, then execute the notebook headlessly with
`python ../../run_notebook.py <notebook> --log <log>` from `metaatomsim-torcwa/`.

`screens/`: one-off family screens (`family_survey.py`: η-capability by structural family; `zinv_screen.py`: z-invariant passive
families scored by Im k_y; `pinwheel_screen.py`: pinwheel vs anisotropy). `migrations/`: scripts that edited existing notebooks
in place during the 2026-10-23 reorganization and v3 solver update (kept for provenance).
